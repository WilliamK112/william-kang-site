Product roadmap

Keep the website as the core product, then reuse the same backend for companion experiences.

1. Website

Full dashboard, charts, tables, filters, project settings, historical data, and secure backend token handling.

2. Chrome extension

Detect the current GitLab project, show a quick summary, and open the matching dashboard in one click.

3. Mobile app

Optional future companion using the same API and analytics logic once the core product is stable.
