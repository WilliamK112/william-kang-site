康景威项目：ClearMove

康景威参与开发的获奖租赁证据整理项目 ClearMove。

康景威Ching-Wei KangWilliam Kang

项目问题

ClearMove 面向租赁交接中的材料整理问题，把租约、检查清单与照片转换为结构清晰、带时间信息的证据文档。

工程实现

项目使用 Next.js、TypeScript、React、Node.js、PostgreSQL、Drizzle ORM、Gemini API 与 pdf-lib，覆盖输入收集、AI 辅助处理、数据存储和 PDF 生成。

项目成果

ClearMove 获得 UW–Madison Badger Build Fest Venture Track Third Prize。公开仓库保留了产品代码与项目说明。
