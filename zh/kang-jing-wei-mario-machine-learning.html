康景威项目：Mario Machine Learning

康景威对 DreamerV3 与 PPO 马里奥强化学习方案的实验。

康景威Ching-Wei KangWilliam Kang

实验目标

Mario Machine Learning 比较 DreamerV3 与 PPO 在 NES Super Mario Bros 1-1 环境中的表现，并记录训练、诊断与结果展示。

工程过程

项目涵盖环境配置、奖励设计、训练运行、失败分析和视频输出。最终的 PPO 基线能够完成关卡，并保留了更好的右侧旗杆通关录像。

学习价值

强化学习项目不仅依赖算法，还依赖稳定环境、可重复实验与清晰指标。这个项目展示了康景威记录完整工程过程的方式。

重点信息

  • DreamerV3
  • PPO
